# Mini-player 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Up Next, shuffle/repeat, seek, pinned lyrics, Recent/Most played/Playlists, sleep timer, hide-in-fullscreen, global hotkeys and compact mode in the desktop mini-player — app only.

**Architecture:** The bridge maps more of the bot's existing API into `BotState` and new commands; Rust validates/caps it and adds three small native modules (sleep, fullscreen, hotkeys); the mini-player UI gets new controls, a queue drawer panel, menu tabs and settings.

**Tech Stack:** Tauri 2.12 (Rust), `windows` 0.62, new `tauri-plugin-global-shortcut` 2.x, plain JS/CSS.

**Spec:** `docs/superpowers/specs/2026-10-11-mini-player-030-design.md`

## Global Constraints

- No bot changes, no bot deploy. Windows only. One new crate: `tauri-plugin-global-shortcut` (2.x).
- Remote page still calls only `bridge_report`; bot/Spotify text rendered with `textContent`.
- Caps: up next 20 items; history/frequent 50; playlists 100; strings 200 chars.
- Settings keys: `miniPlayerCompact` (false), `hideInFullscreen` (true), `hotkeys` (`enabled` false; bindings `playPause` "Ctrl+Alt+P", `skip` "Ctrl+Alt+N", `restart` "Ctrl+Alt+B", `sendSpotify` "Ctrl+Alt+S", `toggleMiniPlayer` "Ctrl+Alt+M").
- Compact closed size 360×64; full 360×170; drawer adds 250.
- Tests: `cargo test --manifest-path desktop/src-tauri/Cargo.toml` · `(cd desktop && npm run -s test:js)`. Stop running app instances before `tauri dev` builds.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Release (version bump, tag) only after Fred tests.

## Review Focus

1. Queue edits racing with a friend's edit (indexes shift) → the app never removes or moves a different song than the one clicked. Pinned in Task 2.
2. Hotkeys: a combination another app owns, the same combination recorded for two actions, AltGr layouts → reported, never silently broken, no duplicate. Pinned in Task 6.
3. Fullscreen: the user re-shows the mini-player during a game, alt-tabs, plays borderless-windowed → the app never fights the user and only restores what it hid. Pinned in Task 5.
4. Compact ↔ full while a drawer is open, near screen edges, on another monitor scale → stays on screen, bottom edge anchored, saved position is the closed one. Pinned in Task 7.
5. Sleep "end of song" with streams/unknown length, a paused bot, a skip → fires once, never pauses the following song unexpectedly. Pinned in Task 4.
